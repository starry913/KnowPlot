# 参考图驱动的科研绘图

**最高目标是美感和艺术感，但这里的美感来自有秩序的科研故事板。** 用户给出的参考图通常有清楚的阶段分区、稳定的阅读方向和密集却有序的局部细节；它们的灵气在不同尺度的对象、框、插画与箭头的组合中，不在任意的异形轮廓、巨大的单一隐喻或横跨画布的长曲线中。科学事实准确不可妥协，视觉结构和文字可读必须支撑美感。

## 入口与素材

用户可给论文、Markdown、数据或一句绘图目标；平时添加参考图时只需图片及三类之一：方法框架图、关键机制示意图、实验数据图。不要要求用户填写出处、标签或“喜欢哪里”。KnowPlot 项目根目录的 `personal_library.py` 提供 `list_references()`，本地图库在 `personal_data/`；在其他项目使用时，先定位其现有图库接口或用户指定的 KnowPlot 目录。

此 skill 独立于 `text2design-agent`；可借鉴其先收集证据再落地设计的方法，但不得修改它。每张新图有自己的 `DESIGN.md`。

## 工作流

1. **核实科学内容。** 从用户原文提取图必须讲清的阶段、输入输出、条件、数据、公式与箭头关系。参考图只提供视觉方法，不能提供本论文的科学事实。实验数据图只使用用户真实数据。
2. **从当前图库看图，分配参考职责。** 每次绘图都重新调用 `list_references()` 读取当时的图库，按图类型和内容浏览候选缩略图，再打开有希望的原图；不能只从 skill 文档里列出的旧图 ID 选。选一张**主参考图**决定宏观分区、面积、阅读顺序和信息密度；再选几张有明确用途的**分参考图**，分别借鉴局部框、对象关系、线条、插画或公式呈现。每项借鉴都要对应当前论文的内容，不为凑数量而借。已观察图的例子见 [图库观察与固定原则](references/principles.md)，但它不是图库的完整清单。
3. **内容进入结构。** 把论文内容分配到有限的阶段/子图。先写清每根箭头的**起点、终点、方向和关系**，再据此排宏观分区与短箭头；不能先摆四周的框，最后用线勉强接到主图。外围模块要接到主流程中真正发生关系的对象，而不是阶段外框或空白处。工具调用与结果返回分别接到**具体工具子框及推理节点**，箭头尖落在对象边界，不能只停在“检索区”的空白里；单向生成、双向工具交互、离线训练、评估输入等关系须分别表达。不能把检索结果画成绕过模型直接生成设计文档，也不能把离线评估画成在线反馈。再借分参考图的局部画法设计大小不一的对象、文本框、公式、局部 image2 素材。承载短文字或公式的小框应由实际渲染后的内容尺寸决定，只留少量均匀内边距，文字在框内水平与垂直居中；不要先画一排等宽框再把文字塞进去。阶段边界和复合机制区则按其包含的全部对象布局。关键文字旁的小图必须代表本论文的对象或操作，尺寸要让读者在论文预期大小下辨认得出；不能只是装饰。每段说明、公式、判断和结果必须在所属组或框内；短对象标签可贴着对象放在小框外。
4. **先写 DESIGN.md。** 按 [设计文档规格](references/design-md.md) 写一版完整、可审阅的结构草图：主参考图与每张分参考图的具体职责、阶段面积关系、各组内容与文字归属、局部图形、箭头、配色、统一手写字体、公式排版及 image2 小素材。若结构选择确有两难，可给第二版比较；不要为了满足“两个方案”而强造视觉隐喻。用户此轮只要求看设计时，到此停止，不进入 Figma。
5. **两道设计关口。** 审美：缩小后像一张组织成熟、局部有生命力的科研图，而非通用卡片模板或松散海报；检查是否被泛泛的文字和大片空白占据。结构：遮住说明文字，只沿箭头走一遍，能否从源对象到目标对象读对生成顺序、返回、训练和评估？主要文字是否有明确归属？任一失败先改分区、连接和内容密度，不靠调色、换圆角或加长弯线补救。补细节时优先用论文中真实的检索记录、步骤、样例、评分条件或数据，使图更具体；不凭空填充术语和装饰。
6. **直接在 Figma 分层绘制。** 需要成图时按 [Figma 绘制与验收](references/figma-loop.md) 执行。全图文字用同一种经实际导出验证的手写字体；公式按数学排版处理上下标、分式、求和界和间距，不把 `exp(x)` 等代码写法当成数学式。文字、公式、形状、箭头和真实数据尽量保留可编辑图层；图片生成模型只制作透明底、无字且与内容强相关的局部语义素材，不画整张图。获取 Figma 实际导出的预览，与主参考图及分参考图的对应局部并排检查，再迭代。

## 分区配色

默认在白画布上按**真实的阶段或功能分区**组织颜色：大分区可去掉边线，铺一层低饱和、接近白色的淡色；采用这种淡彩分区时，区内小框的填充色与所属大区背景色**完全相同**，边线取该区同色系稍深一档。靠框线、尺寸、图标和内容建立层级，不靠白色卡片铺满淡底。颜色用于让读者辨认归属，不能替代箭头表达关系；文字仍用黑色，并检查箭头在淡底上足够清楚。色相和分区数量取决于本轮论文内容与参考图，不固定套用上一张图的四色。大面积浓色、每框换色和渐变会破坏这种层次。详细观察见 [图库观察与固定原则](references/principles.md)。

## 边界

- “最高目标是美感”并不允许篡改数值、关系、公式或用户数据；准确是硬约束。
- 不把参考图整块贴进新图，不照搬其他论文的内容和图标身份；学习其分区、密度与图形语法。
- 不因为个人图库扩大就声称模型已训练或自动学会审美；这是检索、看图、设计转译与人工反馈。
- 默认使用当前 Codex 对话已有能力，不要求用户提供 API Key。Figma 暂不可用时交付本地设计/矢量稿，并明确未作真实画布验收。
