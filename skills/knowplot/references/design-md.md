# 每张科研图的 DESIGN.md

`DESIGN.md` 是绘图前供用户审阅的**结构与视觉施工图**，不是给 image2 生成整张图的提示词。其核心是把论文内容放进从参考图提炼的分区语法，同时保留原创的对象和科学关系。只交设计时停在此文件；不要先建 Figma 场景。

建议按以下内容写，保持具体、可检查，别堆“顶会感”“高级感”等抽象词：

```md
# [论文图暂定名称] · DESIGN.md
> 状态：待审阅 / 已确认 / 已否决
> 图型、来源文件、预期论文版面

## 1. 图要讲的科学故事
- 一句话核心结论；关键阶段、输入输出及分支/反馈；每条事实在原文中的位置。
- 必须在图中的公式、数值、条件；留给正文或图注的信息。
- 图中所有箭头的真实语义；为每条跨阶段或跨分区的线列出“源对象 → 目标对象 / 关系 / 是否为返回线或离线路径”。不能由参考图推导科学事实。
- 从原文摘出适合入图的具体证据，例如一次真实检索命中、一个中间记录、一条轨迹、一个评分条件或一组数据；标明它要解释哪个步骤。案例须标为案例，不能让读者误以为它是整个方法的固定参数。

## 2. 参考图的结构证据
- 亲眼查看的候选图与图像路径。
- 选定的一张主参考图：它的宏观分区类型、各区相对面积、阅读方向和区内密度。说明当前论文为何适合这一结构。
- 几张分参考图：逐项写明参考图的局部做法、当前论文对应的科学内容、准备落在哪个步骤，以及不适合借用的部分。分参考图不改变主参考图的整体骨架。
- 明确不复制的论文内容、图标身份和具体布局。

## 3. 一版完整的结构草图
- 附至少一张带阶段边界、短标题、关键对象、组内文字和箭头的草图；不能只画几个大框或一根曲线。
- 用文字写明：画布的主要分区、每区包含的科学内容、视觉重点、信息密度、相邻区怎样连接。
- 给每区列出“标题 / 关键对象 / 可看见的具体细节”。如果一整区只剩抽象标题、空泛短语与空白，应先回到论文补实质信息，再调整视觉尺寸。
- 用户明确要求对比，或两种宏观结构都适合时，才增加第二版；不得为凑数量强造巨型隐喻。
- 解释哪一部分承载艺术性：对象形态、大小差、局部插画、边界变化、手写字形或留白节奏；不要把自由错位视作艺术性。

## 4. 区内图形蓝图
- 各区的文字归属：公式、说明、条件、结论在哪个框/阶段边界里；框外短标签依附哪个对象。
- 框的差异：短文字和公式先估计实际渲染范围，再加少量均匀内边距定小框大小，并计划文字水平、垂直居中；内容长短自然带来宽高差。实/虚线、圆角按语义选。大框用于真正的阶段或集合，其尺寸由内部全部对象决定。
- 分区配色表：逐区说明“大区淡底 → 内部小框填充与大区背景完全相同 → 小框边线同色系稍深”，并说明哪些大区无需外边线、颜色对应什么科学阶段或功能；白画布与黑字保持统一。不要先选一组固定颜色再强行划分内容。
- 图标/image2 小素材：代表本论文的哪个具体对象或操作、在哪个步骤、放在关键词的哪一侧、预期展示尺寸下是否可辨认；需透明底、无字，不能生成整张图。关键图像不要缩成角标；没有明确内容映射的装饰图标不画。预留真实尺寸的位置，再放文字与箭头。
- 主箭头、辅助线与反馈线的走向；先按语义配对源对象和目标对象，再调整画面位置使线尽量短、少交叉，曲线仅用于真实关系。旁支若是工具调用，要分别写出“推理节点 → 具体工具子框”的查询线和“工具子框 → 推理节点”的观察返回线；不能以外围大区空白代替对象端点。若是训练或评估，要画到受训练的对象或被评估的产物，并与在线生成主轴区分。关系的名称贴着线放，不压住框线。
- 全图统一的手写字体试选（含中文、拉丁字母、数值与公式）；颜色数量与饱和度由参考图和语义分区决定，保证缩小时仍能分区且不会变成彩色卡片墙。列出需要单独排版的指数、上下标、求和界、分式与长公式，说明缩小到论文尺寸时如何检查。论文公式不用代码式 `exp(x)`、`sum(...)` 替代。

## 5. 两道验收
- 审美：与主参考并排缩小看，新图是否同样具备稳固分区、合适密度和活跃的局部细节，而非更空、更乱或更模板？关键小图是否仍能辨认，是否有来自论文的可理解细节填充各区？
- 表达：只沿箭头能否读完科学故事；各线的方向、端点与返回/离线性质是否准确；科学事实与数值是否准确；主要文字是否有归属；缩小时图标、公式、箭头是否仍可辨？
- 需要在 Figma 实际预览后检查的具体风险；当前哪些步骤尚未进行。
```

**草图质量门槛：**必须展示“外层阶段—内层对象—局部文字/箭头”三级，不接受只有大圆、两条分岔线和大片白地的示意。主参考若是左右阶段，新图可以改变阶段数量和比例来适应内容，但应保留分层、密度与区内变化等有用的结构语言。艺术感首先体现在这些组织决定上。

用户否决的 `DESIGN.md` 应标为“已否决”，不可再作为绘图底稿。后续可复用其中经核实的科学事实，不沿用被否定的构图。
